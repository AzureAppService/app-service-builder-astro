# Astro hello-world sample

This sample demonstrates a single Astro page compiled to static HTML and deployed
through App Service Builder. Its audience is a developer starting a small static site.

The root greeting, official framework identity and documentation links are the core
experience. The inline health control checks a published static file. Source customization
is performed in the user's fork and requires a new Builder deployment.

There is no runtime application server, external service, telemetry, credential collection,
counter or in-browser source editor. Local screenshots do not establish hosted qualification.
