# Sample visual foundation

The approved Builder language family uses a pale blue/lavender canvas, a white surface,
system sans typography and restrained ecosystem-specific color. Astro uses the official
dark wordmark on light backgrounds and a warm orange health action.

The reading order is Builder identity and separately named documentation, Astro identity,
one greeting, the inline static-health action and concise expandable source guidance.
Extra cards, counters, editors and operational status decorations are not part of the sample.

Desktop content is bounded to 1080px. Below 700px, navigation wraps and padding contracts;
greeting and documentation remain visible without horizontal scrolling. Keyboard focus is
explicit. Health requests disable the action while pending, report failures and allow retry.
Motion is limited to a short button-color transition and respects reduced motion.

Logos remain independent local image resources; the Astro artwork is not recolored,
combined with the Builder mark or used as this sample's favicon.
